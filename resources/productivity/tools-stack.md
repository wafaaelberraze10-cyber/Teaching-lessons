## Time Management (Todoist / TickTick)
* **Why it matters:** Offloads school task tracking from mental memory into a reliable inbox.
* **Setup:** Create sections: `📥 Inbox` (quick catches), `📝 Grading` (high priority), `📅 Lesson Prep`, `🏫 Administrative`.
* **Best Practices:** Use natural language inputs (e.g., *"Grade essay drafts every Sunday at 2pm"* to set a recurring alert). Add sub-tasks for complex items (e.g., project grades: print rubric -> enter scores -> post online).

## Research & Reading (Zotero & Readwise)
* **Why it matters:** Zotero manages academic research articles, and Readwise compiles highlights from books and articles.
* **Setup:**
  1. Install Zotero desktop and the browser extension.
  2. Set up a free Readwise account (apply for education discounts). Connect Readwise to Kindle, Pocket, or Instapaper.
  3. Set up the Readwise-to-Obsidian/Notion exporter.
* **Best Practices:** Tag every saved research PDF with `Pedagogy`, `Assessment`, or `Linguistics` for quick filtering.

## Visual Collaboration (Miro & Figma)
* **Why it matters:** Miro is a collaborative digital whiteboard; Figma is a user interface/graphic prototyping tool.
* **Setup:** Apply for a Miro Education account (free premium plan with up to 100 team members).
* **Best Practices:** Use Miro for live Socratic discussion maps or plot timelines. Have students use sticky notes to collaborate on paragraph outlines.

---

## Creative Work (Canva)
* **Why it matters:** Visual design platform.
* **Setup:** Apply for Canva for Education (unlocks premium templates and assets). See details in the [Canva AI Guide](../ai/canva-ai.md).
* **Best Practices:** Build consistent design templates for all class worksheets, slides, and syllabus documents to establish a professional classroom brand.
