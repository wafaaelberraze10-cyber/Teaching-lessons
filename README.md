Welcome to the world's most comprehensive open-source AI-powered resource hub designed specifically for English, ESL, EFL teachers, professors, and pre-service educators. This repository houses evidence-based pedagogical guides, massive prompt libraries, downloadable templates, and digital workflows to help you automate administrative tasks, optimize grading cycles, and leverage AI in your classroom.

## 🚀 Getting Started

### 1. For Pre-Service & Student Teachers
Start by reading our comprehensive [College Student & Pre-Service Guide](resources/college-student-guide.md). Learn how to study, structure your digital portfolio on GitHub/LinkedIn, design your first demo lessons, and write a teaching philosophy.

### 2. For Experienced ELA Teachers
Optimize your daily routines using the [Classroom Operating Systems](resources/teaching-systems.md) and learn to set up a digital curriculum wiki using our [Obsidian Setup Guide](resources/productivity/obsidian.md).

### 3. For ESL & EFL Instructors
Differentiate reading text and speech levels using [ChatGPT Differentiated Prompts](resources/ai/chatgpt.md) and design listening tests using [ElevenLabs Voice Generation Guide](resources/ai/elevenlabs.md).

## 🤝 Open-Source Contribution Guidelines

We welcome contributions from educators worldwide! To contribute:

1. **Fork** this repository.
2. Create a new branch: `feature/your-contribution-name`.
3. Keep formatting consistent: use our [Lesson Plan Template](resources/templates/lesson-plan.md) or standard table styles.
4. Open a **Pull Request** detailing what you added or modified.
