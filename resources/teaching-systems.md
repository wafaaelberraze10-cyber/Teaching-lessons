## The Daily Classroom Prep System
A 15-minute checklist completed before students enter the room:

- [ ] **Physical Setup:** Erase whiteboards; organize desks; display lesson objectives.
- [ ] **Digital Setup:** Open browser tabs: LMS dashboard, slides, active timer, digital handouts.
- [ ] **Warm-up Ready:** Place opening prompts on the projector.
- [ ] **Materials Check:** Verify printed handouts, reading texts, or student Chromebook charging stations are ready.

## The Weekly Planning Cycle

```
Monday ──────► Tuesday/Wednesday ──────► Thursday ──────► Friday
Review Data     Draft Core Lessons       Build Assets      Reflect & File
```

* **Monday (Data Review):** Audit the previous week's formative assessments. Adjust pacing based on student gaps.
* **Tuesday & Wednesday (Core Drafting):** Write next week's lesson objectives and core structures (using Backward Design).
* **Thursday (Asset Construction):** Create handouts, slide presentations, and assessment questions (accelerated by AI).
* **Friday (Reflective Filing):** Organize digital files into unit folders. Schedule student communications and postings on the LMS.

## The 4-Step Lesson Creation System
1. **Identify Standard:** Select CCSS or CEFR standard.
2. **Design Assessment:** Write the exit ticket question.
3. **Generate Scaffolding:** Create graphic organizers or vocabulary supports.
4. **Draft Activities:** Structure active learning games or discussion groups.

## Efficient Student Feedback & Grading Workflow
To prevent grading burnout, use a tiered feedback system:

* **Tier 1 (Instant Class Feedback):** Display anonymized student sentences on the board. Correct grammatical errors or structural issues together.
* **Tier 2 (Analytic Rubrics):** Use rubrics to grade formal essays. Write short, bulleted feedback cards instead of dense paragraphs.
* **Tier 3 (AI-Assisted Draft Reviews):** Use a custom prompt with ChatGPT or Claude to provide initial grammatical critiques, allowing you to focus your attention on argument quality.

## The Parent Communication Loop
Keep families informed with a structured communication schedule:

* **Weekly Newsletter:** A simple, 3-bullet email outline detailing:
  1. What students learned this week.
  2. Important deadlines for next week.
  3. One conversation prompt parents can ask their children.
* **The "Good News" Call:** Commit to calling or emailing two parents every Friday to report positive student behavior or academic growth.
