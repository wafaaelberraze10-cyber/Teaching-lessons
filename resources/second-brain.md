## The PARA Method for Teachers

Organize your digital files (Google Drive, Obsidian, or Notion) into four distinct categories:

```
PARA System ──► [Projects] ──► [Areas] ──► [Resources] ──► [Archives]
```

1. **Projects (Active & Time-Bound):** Files with active deadlines.
   - *Examples:* "Grade 10 Macbeth Unit - Fall 2026", "Parent-Teacher Conferences Prep".
2. **Areas (Ongoing Responsibilities):** Roles that require continuous attention.
   - *Examples:* "Classroom Management Routines", "Professional Development Logs", "Curriculum Committee".
3. **Resources (Interests & Reference Material):** Reference collections you can pull from.
   - *Examples:* "ESL Vocabulary Prompts", "Writing Activity Templates", "Graphic Organizers".
4. **Archives (Inactive Files):** Completed items kept for reference.
   - *Examples:* "English Class Syllabi - 2025", "Grants applied for - 2024".

## Building a Digital Reference Library
* **Zotero for Academic Research:** Use Zotero to save, tag, and cite educational research articles. Connect it with MS Word or Google Docs for easy bib entry.
* **Readwise for Articles:** Use Readwise to capture highlights from online articles, newsletters, and Kindle books, exporting them directly to Obsidian or Notion.

## AI Workflow Integration
* **Prompt Collections:** Keep a folder in your notes app dedicated to prompt skeletons (e.g., [Prompts Index](prompt-library/prompts.md)).
* **NotebookLM Databases:** Upload all syllabi, assignments, and policies for a semester to NotebookLM to create an instant FAQ database.
