## The First Day of School Checklist
- [ ] **Physical Prep:** Set up seating charts; label name tags.
- [ ] **Tech Prep:** Verify students can log in to Google Classroom or school LMS.
- [ ] **Syllabus Ready:** Print or share digital syllabus including AI policies.
- [ ] **Icebreaker Active:** Put opening hook on board.
- [ ] **Classroom Rules:** Outline 3 core expectations (Respect, Integrity, Preparation).

---

## Weekly Closeout Checklist (Friday Afternoon)
- [ ] **Grading Inbox Zero:** Enter all formative scores into gradebook.
- [ ] **Week Planning Complete:** Review next week's lesson drafts.
- [ ] **Materials Scheduled:** Queue digital posts on LMS for Monday.
- [ ] **Desk Reset:** Clean whiteboards; file papers; organize bookshelves.

---

## Exam Day Prep Checklist
- [ ] **Seating Arrangement:** Move desks apart to ensure privacy.
- [ ] **Tech Lockdown:** Turn on browser lock settings on school computers.
- [ ] **Paper Prep:** Print exam sheets and extra reference pages.
- [ ] **Proctor Focus:** Set timer on board; remove phone distractions.
