## Google Workspace for Education Setup
* **Google Classroom Structure:** Organize assignments by topic tabs (e.g., *Week 1: Essay Outlines*, *Week 2: Drafts*). Keep a permanent "Class Resources" tab at the very top for syllabus and links.
* **Google Drive PARA Folders:** Set up shared Google Drive folders with student teachers or colleagues using clear labeling: `Grade_10_ELA_Drive`.
* **Google Docs Extensions:** Use voice typing for verbal grading feedback and install the Gemini extension to draft rubrics and worksheets inline.

---

## Microsoft 365 for Education Setup
* **OneNote Class Notebook:** The premier tool for digital student portfolios. Set up sections for:
  - **Content Library:** Teacher-shared readings and syllabus sheets.
  - **Collaboration Space:** Group writing exercises.
  - **Student Notebooks:** Individual private workspaces where you can view student drafting in real time.
* **Microsoft Teams for Education:** Use channels for different units and set up Assignment rubrics directly within Teams Assignments.

## Core Educator Keyboard Shortcuts

| Action | Google Workspace | Microsoft 365 |
| :--- | :--- | :--- |
| **Insert Link** | `Ctrl + K` | `Ctrl + K` |
| **Paste Plain Text** | `Ctrl + Shift + V` | `Ctrl + Shift + V` |
| **Comment** | `Ctrl + Alt + M` | `Ctrl + Alt + M` |
| **Voice Typing** | `Ctrl + Shift + S` (in Docs) | `Win + H` |

## AI Integration Tips
* **Google Docs:** Type `@Gemini` inside Google Docs (if enabled by school administration) to generate outlines, quizzes, or simplify highlighted text.
* **Microsoft Word:** Click the Copilot icon in the document margin to write prompts or draft letters based on notes.
